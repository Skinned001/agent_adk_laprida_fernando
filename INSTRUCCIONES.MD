Instrucciones

Actividad Práctica:

Desarrollar un agente de inteligencia artificial utilizando Python y Google Agent Development Kit (ADK), capaz de resolver un problema concreto mediante el uso de herramientas. El agente deberá interpretar las solicitudes del usuario, determinar qué acciones necesita realizar, utilizar las herramientas disponibles y construir una respuesta a partir de los resultados obtenidos.

No se considerará suficiente implementar un chatbot que únicamente genere respuestas mediante un modelo de lenguaje.

Modelo de IA: utilizar un modelo compatible con Google ADK, mediante LiteLLM u otra configuración trabajada en clase.

Instrucciones: definir el rol, el objetivo, las restricciones y el comportamiento esperado del agente.

Herramientas: implementar al menos tres herramientas con responsabilidades diferentes.

Uso de herramientas: demostrar que el agente puede seleccionar herramientas según la solicitud recibida.

Validación: contemplar errores, argumentos inválidos y resultados vacíos.

Interfaz de prueba: ejecutar el agente mediante la interfaz web de ADK o una alternativa acordada.

Importante: La entrega se debe realizar en un repositorio de github con la siguiente nomenclatura: agent_adk_nombre_apellido, con su correspondiente README.md explicando de que se trata, que herramientas tiene y cómo utilizarlo.
